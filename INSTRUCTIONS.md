## Run Instructions ##

# Prerequisites
- Node.js (v16 or higher)
- npm
- Git

# Setup & Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/reuven-itzhakov/library-explorer
   cd library-explorer
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm start
   ```
   The app will open at [http://localhost:3000](http://localhost:3000)
